# @naandalist/patch-package

> **Deprecated.** Do not use in new projects.

This fork existed to patch Snyk findings in `patch-package` v8.0.0.
Official [`patch-package@8.0.1`](https://www.npmjs.com/package/patch-package)
covers that now. Prefer native `yarn patch`, `pnpm patch`, or `npm patch`.

```bash
npm uninstall @naandalist/patch-package
npm install -D patch-package
```

Existing `patches/` files still work with the official package.

Original `patch-package` is by [David Sheldrick](https://github.com/ds300).
